# 🔐 Desafio Login Page

Uma página de login moderna e responsiva desenvolvida com HTML, CSS e JavaScript como parte dos meus estudos em desenvolvimento front-end.

O objetivo deste projeto foi praticar a construção de interfaces modernas, responsividade e organização de código, transformando um design estático em uma experiência agradável para o usuário.

## ✨ Funcionalidades

* Interface moderna e intuitiva
* Campos de login estilizados
* Feedback visual para interação do usuário
* Layout responsivo
* Compatível com desktop e dispositivos móveis
* Estrutura semântica utilizando HTML5

## 💻 Como Executar Localmente

1. Clone o repositório:

```bash
git clone https://github.com/devKauaHenrique/Desafio-login-page.git
```

2. Entre na pasta:

```bash
cd Desafio-login-page
```

3. Abra o arquivo `index.html` no navegador.
